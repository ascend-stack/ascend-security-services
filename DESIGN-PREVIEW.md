# Ascend metallic brand preview

Responsive homepage based on the selected corporate mockup. SVG logo uses the approved entity colors with a contrasting orbit. Backgrounds are newly generated standalone illustrations inspired by the mockup, not actual facilities, personnel, or engineered products.

No build step. Open index.html with a local web server, or use your existing static hosting preview. The main branch and existing deployment settings are unchanged. Existing secondary pages are preserved.

The IP inquiry form opens an email draft and does not send or store submissions.
